# Rent Calculator

A simple command-line Python program that calculates the rent amount per person based on the total rent, number of people, and other expenses.

## Features 

- Takes total rent as input
- Calculates additional expenses
- Splits the total amount between people
- Displays the amount each person needs to pay

## Requirements

- Python 3.x

## How to Run

```bash
python3 main.py
